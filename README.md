# 🏛️ AI Mock Test System

A professional Streamlit-based assessment platform for BCA, B.Com, BBA, and PUC students.

## ✨ Key Features
* **Timed Assessments:** 10-minute mock exams via real-time API.
* **Smart Dashboards:** Contextual performance tracking with gold-themed analytics.
* **Study Planner:** Automated study prescriptions and curated learning resources.
* **Secure Backend:** Integrated with Supabase for data management.

## 🛠️ Tech Stack
* **Frontend:** Streamlit (Python)
* **Database:** Supabase
* **Data Visualization:** Plotly & Pandas
